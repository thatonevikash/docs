<p>Snippets are like auto completing a portion of code block which looks minimal but it present most within the code or codebase.</p>
<p>In my case, I wanted to make the code structure beautiful using the comments to separate code blocks.</p>

<h3>How to add snippet?</h3>
<p>For generating the comment divider pressing the <code>-</code> multiple times is not a better way to do this.</p>
<p>Copy and Pasting it across the entire codebase is not also an optimal solution.</p>
<p><strong>More Collaborators = Multiple Machines</strong></p>
<div class="alert alert-important"><div class="alert-header"><span class="alert-icon"><svg xmlns="http://www.w3.org/2000/svg" width="18" height="18" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true" class="alert-icon-svg"><path d="M22 17a2 2 0 0 1-2 2H6.828a2 2 0 0 0-1.414.586l-2.202 2.202A.71.71 0 0 1 2 21.286V5a2 2 0 0 1 2-2h16a2 2 0 0 1 2 2z"></path><path d="M12 15h.01"></path><path d="M12 7v4"></path></svg></span><span class="alert-label">Important</span></div>
<p>This snippet will work within vscode.</p>
<p>Your default snippets can not be triggered by any other machine. ( <strong>if you set it in default <code>settings.json</code></strong> )</p>
</div>
<p><strong>Steps</strong></p>
<ul>
<li>
<p>create <code>.vscode</code> folder at root of your codebase.</p>
</li>
<li>
<p>create a file as <code>.vscode/style.code-snippets</code></p>
</li>
</ul>
