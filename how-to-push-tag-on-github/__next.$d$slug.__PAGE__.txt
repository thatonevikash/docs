f:T957,<h2>Best way to push tag on <code>github</code></h2>
<h3>Noob approach of pushing a tag</h3>
<p>If you are using the command as</p>
<pre><code class="hljs language-bash"><span class="hljs-comment"># lists all tags</span>
git tag

<span class="hljs-comment"># creates a new tag</span>
git tag v0.1.1
</code></pre>
<p>Then you push on that tag</p>
<pre><code class="hljs language-bash"><span class="hljs-comment"># push on github</span>
git push origin v0.1.1
</code></pre>
<div class="alert alert-important"><div class="alert-header"><span class="alert-icon"><svg xmlns="http://www.w3.org/2000/svg" width="18" height="18" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true" class="alert-icon-svg"><path d="M22 17a2 2 0 0 1-2 2H6.828a2 2 0 0 0-1.414.586l-2.202 2.202A.71.71 0 0 1 2 21.286V5a2 2 0 0 1 2-2h16a2 2 0 0 1 2 2z"></path><path d="M12 15h.01"></path><path d="M12 7v4"></path></svg></span><span class="alert-label">Important</span></div>
<p>It doesn't update your <code>package.json</code><br>
It doesn't anchor your package version.</p>
</div>
<p>Now have to manually update the package version and push it separately.</p>
<pre><code class="hljs language-bash"><span class="hljs-comment"># 1. update package version</span>
npm version patch

<span class="hljs-comment"># 2. push a separate commit</span>
git push
</code></pre>
<div class="alert alert-note"><div class="alert-header"><span class="alert-icon"><svg xmlns="http://www.w3.org/2000/svg" width="18" height="18" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true" class="alert-icon-svg"><circle cx="12" cy="12" r="10"></circle><path d="M12 16v-4"></path><path d="M12 8h.01"></path></svg></span><span class="alert-label">Note</span></div>
<p>patch for <code>0.0.*</code><br>
minor for <code>0.*.0</code><br>
major for <code>*.0.0</code></p>
</div>
<h3>Pro approach of pushing a tag</h3>
<pre><code class="hljs language-bash"><span class="hljs-comment"># 1. Bumps version, updates package.json, commits, and tags locally</span>
npm version patch

<span class="hljs-comment"># 2. Pushes the commit to main AND pushes the newly created tag simultaneously</span>
git push origin main --follow-tags
</code></pre>
