f:T2725,<h2>JavaScript</h2>
<p><strong>JavaScript: The dynamic language of the web.</strong></p>
<p>JavaScript is a programming language that brings web pages to life.<br/>
It's the core technology of the web, working alongside HTML and CSS.<br/>
While HTML structures the content and CSS styles it.<br/>
JavaScript adds <em>interactivity</em> and <em>dynamic behaviour</em>.</p>
<hr>
<h3>What can we do with JavaScript ?</h3>
<ul>
<li><strong>Create interactive elements</strong>: <code>button</code>s, <code>menu</code>s, <code>slider</code>s, etc.</li>
<li><strong>Animate graphics and images</strong>: Create engaging visual effects.</li>
<li><strong>Update content dynamically</strong>: Load new data without reloading the page.</li>
<li><strong>Build web applications</strong>: Complex applications like online stores, social media platforms.</li>
<li><strong>Develop server side applications</strong>: Using Node.js, you can create backend systems.</li>
</ul>
<h3>Key characterstics of JavaScript</h3>
<ul>
<li><strong>Lightweight and Interpreted</strong>: It runs directly in the browser without needing compilation.</li>
<li><strong>Cross-Platform</strong>: Works on different operating systems and browsers.</li>
<li><strong>Object-Oriented</strong>: Supports object-based programming for code organization.</li>
<li><strong>Dynamically types</strong>: You don't need to specify data types beforehand.</li>
</ul>
<h2>History of JavaScript</h2>
<h3>Birth of JavaScript</h3>
<ul>
<li>
<p><strong>1995</strong><br/><em>Brenden Eich</em>, a programmer at <strong>Netscape Communication</strong>, created JavaScript in a mere 10 days. Initially named <strong>Mocha</strong>, it was later renamed <strong>LiveScript</strong> and finally <strong>JavaScript</strong> to capitalize on the popularity of <strong>Java</strong> at the time.</p>
</li>
<li>
<p><strong>Purpose</strong><br/>Designed to add interactivity to static HTML pages, JavaScript brought life to the web.</p>
</li>
</ul>
<h3>Early years and Browser's war</h3>
<ul>
<li>
<p><strong>1996 - 1997</strong><br/>JavaScript gained rapid adoption with <strong>Netscape Navigator</strong> and <strong>Internet Explorer</strong> becoming the dominant browsers.</p>
</li>
<li>
<p><strong>Browser wars</strong><br/>Intense competiton between <strong>Netscape</strong> and <strong>Microsoft</strong> led to different JavaScript implementations, causing compatiblity issues.</p>
</li>
<li>
<p><strong>ECMAScript</strong><br/>To standardize the language, <em>ECMA International</em> created <strong>ECMAScript</strong>, a specification for JavaScript.</p>
</li>
</ul>
<h3>Growth and Maturity</h3>
<ul>
<li>
<p><strong>1997 - 2000</strong><br/>The Document Object Model ( <strong>DOM</strong> ) and Dynamic HTML ( <strong>DHTML</strong> ) emerged, expanding JavaScript capablities.</p>
</li>
<li>
<p><strong>2006 - 2010</strong><br/><strong>jquery</strong> and other libraries simplified JavaScript development and popularized its use.</p>
</li>
<li>
<p><strong>2009 - 2015</strong><br/>ECMAScript 5 and 6 introduced significant improvements, making JavaScript a more robust language.</p>
</li>
</ul>
<h3>Modern JavaScript</h3>
<ul>
<li>
<p><strong>2015 onwards</strong><br/>JavaScript has evolved rapidly, becoming a full-fledge language for building complex applications.</p>
</li>
<li>
<p><strong>Node.js</strong><br/>Revolutionized server-side development with JavaScript, enabling full stack development.</p>
</li>
<li>
<p><strong>Frameworks and Libraries</strong><br/>React, Angular, Vue, and others emerged, providing powerful tools for building user interfaces.</p>
</li>
</ul>
<h2>Creation of server-side JavaScript</h2>
<p>While JavaScript initially designed for the client-side, its versatility and popularity led to its expansion into server-side development.</p>
<h3>Early attempts</h3>
<ul>
<li>
<p><strong>Before Node.js</strong><br/>Several attempts were made to run JavaScript on the server, but they lacked widespread adoption.</p>
</li>
<li>
<p><strong>Challenges</strong><br/>Performance, scalablity, and ecosystem limitations hindered these early efforts.</p>
</li>
</ul>
<h3>The rise of Node.js</h3>
<ul>
<li>
<p><strong>2009</strong><br/><em>Ryan Dahl</em> released Node.js, a JavaScript runtime built on chrome's V8 Javascript engine.</p>
</li>
<li>
<p><strong>Event-driven architecture</strong><br/>Node.js's non-blocking, event-driven approach made it highly efficient for handling concurrent connections.</p>
</li>
<li>
<p><strong>Package ecosystem</strong> ( <strong>npm</strong> )<br/>A vast collection of reusable modules accelerated development.</p>
</li>
<li>
<p><strong>Full-Stack JavaScript</strong><br/>Developers could now use JavaScript for both front-end and back-end development.</p>
</li>
</ul>
<h3>Impact of Node.js</h3>
<ul>
<li>
<p><strong>Rapid growth</strong><br/>Node.js gained immense popularity, becoming a preferred choice for server-side development</p>
</li>
<li>
<p><strong>Diverse application</strong><br/>Used for web servers, real-time applications, APIs, and more.</p>
</li>
<li>
<p><strong>Ecosystem expansion</strong><br/>A thriving ecosystem of frameworks, libraries, and tools emerged.</p>
</li>
</ul>
<h3>Beyond Node.js</h3>
<ul>
<li>
<p><strong>Other options</strong><br/>While Node.js dominates the server-side JavaScript landscape, alternatives like Deno have emerged.</p>
</li>
<li>
<p><strong>Continued evolution</strong><br/>JavaScript and Node.js are constantly evolving, with new features and improvements enhancing their capablities.</p>
</li>
</ul>
